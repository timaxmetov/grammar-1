# Tikitaka — Present Perfect Continuous

Интерактивный разбор темы Present Perfect Continuous: формула, диаграмма-таймлайн, диалоги с озвучкой (Web Speech API), реальные видео на YouTube (RU для A0–A2, EN для B1–C1) и три типа упражнений с проверкой.

Открыть: [index.html](index.html) в любом браузере (или включите GitHub Pages в настройках репозитория, чтобы получить прямую ссылку).

Сделано в стиле разборов Tikitaka — коротко, по делу, без зубрёжки.
